## 1단계에서 만든 것
- **기반**: Godot 4.3 프로젝트(640×360 정수배, nearest, 60fps), 폴더 구조, `CLAUDE.md`, `docs/ASSETS.md`
- **데이터**: 무기 54종, 스킬 54개(무기군 8×6 + 크로노 6), 방어구(번영의 숲 예시 6 + 외형 시험용 2), 소모품 6, 재료 13, 상태이상 8(+띄우기·시간 정지·그로기), 등급·추가 옵션 풀, 밸런스 공식 계수 전부. 로더가 개수·공식·참조를 검증한다.
- **입력**: 기본 키 배치(GDD 12-4), 키 재설정, 선입력 버퍼 0.15초, 설정 저장(`user://settings.cfg`)
- **디버그 콘솔**: `` ` ``/`F1`. 레벨, 아이템·스킬서 지급, 스킬 습득, 무적, 히트박스 표시, 몬스터 소환, 크로노포스 등
- **캐릭터**: 레이어 구조(그림자·망토·몸·신발·갑옷·장갑·결정 무늬·머리·투구·무기·앞망토), 장비·머리색·망토색·크로노포스 단계에 따라 외형 변경
- **전투**: 상태 머신, 8방향 이동, 조준 보정(±30°, 설정에서 끄기), 대시(0.2초 무적·2회 충전·캔슬), 패링/가드, 저스트 회피, 무기 6군 콤보·방향 파생기·차지·대시 공격·특성, 무기 등급·추가 옵션·고유 효과 30종, 무기 숙련도
- **스킬**: 스킬 54개 전부 동작, 스킬 레벨(피해 +12%, Lv3 쿨 -15%, Lv5 강화), 기력 게이지, 스킬서 카드 3장 제안
- **피해 파이프라인**: GDD 6-2 순서, 상태이상, 그로기, 경험치·레벨·스탯, 크로노포스 보정
- **타격감**: 히트스톱(3/5/8프레임), 화면 흔들림, 흰색 번쩍임, 넉백, 등급색 궤적, 불꽃·결정 조각 파티클, 데미지 숫자(일반 흰색/치명 노랑/받는 피해 빨강)
- **UI**: HUD 전체, 인벤토리, 장비, 스탯, 스킬, 키 설정창(키보드 그림 + 드래그), 일시정지 메뉴(설정 포함), 창 드래그·위치 저장, 비교 툴팁
- **테스트 구역**: 허수아비 2개(Lv1·Lv10, DPS 표시) + 공격해 오는 테스트 몬스터 2마리 (패링 연습)
- **자동 테스트** `tests/run_tests.tscn` 384개 항목 통과, **웹 빌드** `play/`

## 남은 문제 (다음 단계에서)
- **소리 없음**: 무기군별 타격음(5-6), 창 열기 효과음(12-1) 없음. 사운드 에셋 단계에서
- **문구 파일 분리(12-8) 미완**: `Text` 전역과 `data/text_ko.json` 자리만 있고 UI 문구는 아직 코드 안에 있다
- **애니메이션은 임시**: 프레임 수 규격만 맞췄고 무기군별 콤보 동작(11-4)이 따로 없다. 공격은 공통 동작 + 무기 회전
- **광원·노멀맵·낮밤(12-5)**: 4단계. 결정 무늬 4단계 '캐릭터 자체가 약한 광원', 반딧불 목걸이 광원, 새벽빛 화살 빛은 아직 효과 없음
- **몬스터**: 길찾기 없음(직선 추적), 몬스터 애니메이션 없음, 드롭표는 테스트용 (3단계)
- **저장 없음**: 설정·키 배치·창 위치만 저장. 진행 저장(3개 슬롯, 12-8)은 8단계
- **타이틀·캐릭터 생성 없음**: 머리색·망토색은 디버그 `look` 명령으로만 바꿀 수 있다
- 월드맵(M)·도감(J)은 키만 있고 알림만 뜬다
- 제작대·강화·분해 없음 (강화 단계는 아이템 수치 계산에만 반영)
- 물약 마시기 동작(6프레임)을 따로 재생하지 않는다
- 키 설정창 드래그와 창 위치 저장은 자동 테스트가 로직만 확인했다. 마우스로 직접 확인 필요
- 웹 빌드는 단일 스레드 템플릿, 첫 로딩 약 38MB
