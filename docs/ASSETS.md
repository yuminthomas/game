# 에셋 규격과 교체 규칙

지금 게임의 그래픽은 전부 코드로 그린 **임시 도트**다 (`scripts/core/SpriteFactory`). GDD 11-5 전략대로, 아래 경로에 **같은 규격의 PNG** 를 넣으면 코드 수정 없이 그 그림이 쓰인다.

- 파일이 있으면 그 파일을, 없으면 임시 도트를 쓴다 (`SpriteFactory._path_tex`).
- PNG 를 추가한 뒤 Godot 에디터를 한 번 열거나 `godot --headless --import` 를 실행해 가져오기(import)를 해야 인식된다.
- 모든 그림은 nearest 필터로 그려진다. 반투명 가장자리 없이 픽셀 단위로 그린다.
- 외곽선은 `#14121f` 1px 를 권장 (어느 배경에서도 잘 보이게, GDD 11-2).

## 1. 플레이어 (레이어 캐릭터)

경로: `assets/sprites/player/<레이어>/<변형>/<동작>.png`

| 항목 | 규격 |
|---|---|
| 프레임 | 48×48 px |
| 원점 | 프레임 안 (24, 42) = 발밑 중앙. 몸은 약 16×26 px |
| 시트 배치 | 가로 = 프레임 순서, 세로 = 방향 5줄 |
| 방향 줄 순서 | 0 아래, 1 아래대각(오른쪽 아래), 2 옆(오른쪽), 3 위대각(오른쪽 위), 4 위. 왼쪽은 좌우 뒤집기 |

### 레이어 (아래부터 그려지는 순서)
| 레이어 | 변형(variant) | 색 | 설명 |
|---|---|---|---|
| (그림자) | — | 코드 | 발밑 타원 |
| `cape_back` | `default`, `short`, `long` | **회색조** → 망토색으로 물듦 | 뒷망토. 아래·대각·옆 방향에서 보임 |
| `body` | `default` | 원래 색 | 피부, 튜닉, 벨트, 바지 |
| `feet` | `default` | **회색조** → 신발 색 | 부츠 |
| `armor` | `plate` (`none` = 그리지 않음) | **회색조** → 갑옷 색 | 갑옷 |
| `hands` | `default` | **회색조** → 장갑 색(없으면 피부색) | 손 |
| `crystal` | `0`~`4` | 원래 색 (청백 `#bff3ff`) | 결정 무늬 5단계 (GDD 11-2) |
| `hair` | `default` | **회색조** → 머리색 | 머리카락 |
| `helmet` | `hood`, `helm` (`none`) | **회색조** → 투구 색 | 두건·투구 |
| (무기) | — | — | 아래 2번. 손 위치에 따로 그려져 공격할 때 회전한다 |
| `cape_front` | `default`, `short`, `long` | **회색조** → 망토색 | 앞망토. 위·위대각 방향에서 보임 |

**회색조 레이어**는 밝은 회색(약 `#e6e6ea` / `#bcbcc4` / `#8e8e98` 세 단계)으로 그린다. 게임이 `modulate` 로 색을 곱해 머리색·망토색 6가지(GDD 11-2)와 장비 색을 입힌다.
GDD 11-3 의 레이어 목록에 장갑·신발 색 반영(GDD 9-2)을 위해 `feet`, `hands` 를 더했다.

### 노멀맵
GDD 12-5 의 광원은 4단계에서 붙인다. 같은 경로에 `<동작>_n.png` 이름으로 노멀맵을 둘 자리를 예약해 둔다.

## 2. 무기
경로: `assets/sprites/weapons/<무기id>.png` (무기 id 는 `data/weapons.json`)
- 40×16 px, **오른쪽을 향하게**, 손잡이 쥐는 점이 (4, 8).
- 이 그림이 캐릭터 손에 붙어 공격 방향으로 회전한다. 같은 그림이 아이콘에도 축소되어 쓰인다 (아이콘을 따로 넣으면 그쪽 우선).
